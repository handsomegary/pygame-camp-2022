# 營隊學習指南

這個專案依照 2022 年 Pygame 營隊的主題，重新撰寫可執行的 Python 範例。先練習語法、容器與類別，再閱讀 Popcat 和貪食蛇的程式。基礎範例只使用 Python 標準函式庫；遊戲另需安裝 `pygame`。

## 建議學習順序

在專案根目錄執行：

```console
python -m examples.basics
python -m examples.basics --number 8
python -m examples.containers
python -m examples.classes
```

這些範例會直接輸出結果並結束，不會停在 `input()` 等待輸入。命令列參數也會先以字串傳入，再轉型、驗證。例如 `--number -1` 或 `--number hello` 會顯示輸入錯誤。

## 基礎語法與遞迴

`factorial(n)` 計算階乘：`factorial(0) == 1`、`factorial(5) == 120`。`fibonacci(n)` 回傳第 n 個費氏數，採用 `F(0) = 0`、`F(1) = 1`；因此 `fibonacci(6) == 8`。

兩個函式都只接受非負整數。傳入字串、小數或布林值會得到 `TypeError`，負數會得到 `ValueError`。Python 的 `bool` 是 `int` 的子類別，但此處將它排除，以免把 `True` 誤當成數字 1。

一般版本使用迴圈。`factorial_recursive()` 和 `fibonacci_recursive()` 則用來示範講義中的遞迴：函式呼叫自己，並且一定要有停止條件。階乘遞迴版限制在 0 到 100，費氏遞迴版限制在 0 到 20，避免深度過大或大量重複計算。想計算更大的數字，改用迴圈版本。

## 容器與亂數

| 容器 | 可以修改容器嗎？ | 順序 | 重複元素 |
| --- | --- | --- | --- |
| `str` | 不可以 | 保留字元順序 | 可以 |
| `list` | 可以 | 保留元素順序 | 可以 |
| `tuple` | 不可以 | 保留元素順序 | 可以 |
| `dict` | 可以 | 保留鍵的插入順序 | 鍵不重複，值可重複 |
| `set` | 可以 | 不保證迭代順序 | 不重複 |
| `frozenset` | 不可以 | 不保證迭代順序 | 不重複 |

講義中的容器表有兩處需要修正：現代 Python 的 `dict` 保留插入順序，這在 Python 3.7 起是語言保證；`set` 是可變的，不可變的版本叫 `frozenset`。集合的列印順序不能當成程式邏輯，因此範例使用 `sorted()` 顯示集合結果。

`tuple` 不可變是指其中的參照不能被新增、刪除或重新指派；如果它包含 `list`，那個 `list` 的內容仍然可以修改。`dict` 的鍵與集合元素必須可雜湊，例如字串、整數或只含可雜湊元素的 tuple；list 不能直接作為它們的鍵或元素。

`random.Random(2022)` 使用固定種子，讓這份練習每次得到相同的示範結果。遊戲中的亂數可以使用不同種子；固定種子很適合重現錯誤或比較修改前後的行為。

## 類別、繼承與覆寫

`Animal` 將名字、技能和行為放在一起；`Dog`、`Cat` 繼承它並覆寫 `talk()`。對不同物件呼叫相同方法會產生不同結果，這就是範例中的多型。

`self.tricks = []` 放在 `__init__()` 裡，讓每個物件都有自己的串列。如果把 `tricks = []` 直接放在類別本體，且各實例都透過它新增技能，就會修改同一個共享串列。可變的預設參數也有類似風險；需要每次建立新串列時，應以 `None` 作為預設值，再在函式內建立 `[]`。

Python 不會因為引數數量或型別不同，自動把重複的 `def talk(...)` 當成多載。相同作用域中後面的定義會取代前面的定義。初學時可用預設參數或不同函式名稱處理不同用法；子類別的方法覆寫則如本範例所示。

`__name` 這類雙底線名稱會觸發名稱改寫（name mangling），主要用途是避免子類別不小心撞名，不是安全存取控制；仍然可以透過改寫後的名稱存取。單底線 `_name` 表達「內部使用」慣例。`__init__`、`__str__` 這類前後都有雙底線的名稱是 Python 特殊方法，不屬於上述改寫規則。

類別不一定要自行定義 `__init__()`；沒有新初始化需求時，可以沿用父類別的初始化方法。多重繼承的搜尋順序遵循方法解析順序（MRO），不能一律用簡單的「先找完整的左邊，再找右邊」說明；可以用 `SomeClass.__mro__` 查看實際順序。

## 其他講義細節

- Python 的布林常數是 `True`、`False`，大小寫有意義。
- `input()` 的結果是字串；要計算數值必須轉型，並處理無效輸入。
- 變數名稱也可以使用許多 Unicode 字元；這個專案採用英文識別字，方便跨平台閱讀與合作。
- Python 程式通常先編譯成位元組碼再由直譯器執行；垃圾回收會在執行期間處理物件生命週期，不是只在編譯時收回記憶體。
- `*`、`/`、`//`、`%` 的優先順序相同，通常由左至右計算；`**` 由右至左結合。例如 `2 ** 3 ** 2` 等同 `2 ** (3 ** 2)`。
- Pygame 遊戲以事件迴圈處理輸入，再更新狀態與畫面。不要在迴圈裡放長時間的等待或 `input()`，否則視窗會無法即時回應。
